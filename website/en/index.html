Security First

Sensitive data blocked before reaching models

Database passwords, API keys, SSH private keys won't leave your machine just because an agent read a file. OwnCoder automatically detects and replaces them with [REDACTED] before sending requests.

01

File Matching

60+ built-in globs covering .env, *.pem, *.key, kubeconfig, terraform variables, and other sensitive files.

02

Format Recognition

25+ key format patterns: OpenAI, AWS, GCP, GitHub tokens, database connection strings, JWT, PEM private key blocks, etc.

03

Keyword Fallback

Recognizes password, secret, token, and environment variable suffixes like *_PASSWORD to reduce leaks.

Two Redaction Levels

  • Value-level redaction: Masks only sensitive fields while preserving structure, allowing agents to understand configuration format.
  • Full-file redaction: Entire private keys and certificates are masked, agents only know "this is sensitive."
  • Customizable rules: Add your own globs and patterns in settings, with local preview validation.

Local-First · No Cloud Index

No code upload, no cloud indexing

Analysis, search, embeddings, and experience memory all run on your machine. No "cloud knowledge base" syncing repos to third-party servers.

Fully Local Index System

Unified SQLite + FTS5 index: symbol search, full-text retrieval, experience indexing with incremental scanning respecting .gitignore.

  • 35+ language symbol indexing (tree-sitter)

  • Data stays on your machine, never touches OwnCoder cloud

Privacy Built Into Defaults

  • No code upload: Source code never synced to OwnCoder servers
  • No cloud indexing: No remote vector DB or code repo mirrors
  • Zero telemetry: No usage data collection, crash reports, or analytics
  • Full control: Keys and workspace data always on your machine

Core Capabilities

Beyond security, equally powerful

Plan and Agent dual modes, execution-level verification, inline change review—turning AI coding into an auditable, reversible engineering workflow.

Plan + Agent

Plan mode for read-only analysis and proposals; Agent mode for editing files, running commands, and tests. Think first, then act.

Execution-Level Verification

Auto-runs type checks, linting, and related tests after changes; enters auto-fix loop on failure instead of "looks like it works."

Inline Change Review

Shows file-by-file diffs after each operation, with per-file keep/undo and batch keep/undo all support.

Write & Command Protection

Three-tier write policies prevent accidental critical path modifications; dangerous commands require confirmation, timeout defaults to deny (fail-closed).

High Cache Hit Rate

Context optimized for real billing scenarios, impressive cache hit rates make daily iteration more token-efficient.

Open Model Integration

Compatible with any OpenAI Chat Completions API: DeepSeek, Tongyi, Zhipu, Moonshot, etc.—bring your own config.
