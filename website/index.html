安全第一

敏感信息，发往模型前就被挡住

数据库口令、API Key、SSH 私钥不会因为一次 Agent 读文件就离开你的机器。 OwnCoder 在请求发出前自动检测并替换为 [REDACTED]。

01

文件匹配

60+ 内置 glob，覆盖 .env、*.pem、*.key、kubeconfig、terraform 变量等敏感文件。

02

格式识别

25+ 种密钥格式正则：OpenAI、AWS、GCP、GitHub Token、数据库连接串、JWT、PEM 私钥块等。

03

关键词兜底

识别 password、secret、token 以及 *_PASSWORD 等环境变量后缀，减少漏网。

两种脱敏粒度

  • 值级脱敏：仅掩码敏感字段，其余结构仍可读，Agent 能理解配置形态。
  • 全文件脱敏：私钥、证书等整文件掩码，Agent 只知道“这是敏感文件”。
  • 可自定义规则：在设置中追加 glob 与正则，并支持本地预览验证。

本地优先 · 无云端索引

代码不上传，索引也不上云

分析、检索、嵌入与经验记忆都在你的电脑上完成。没有把仓库同步到第三方服务器的“云端知识库”。

完全本地的索引体系

基于 SQLite + FTS5 的统一索引：符号搜索、全文检索、经验索引，增量扫描并遵循 .gitignore。

  • 35+ 语言符号索引（tree-sitter）
  • 本地 RAG 嵌入，可离线使用
  • 数据只落在本机，不经过 OwnCoder 云

隐私承诺写进产品默认值

  • 不上传代码：源码不会被同步到 OwnCoder 服务器
  • 无云端索引：没有远程向量库 / 远程代码仓镜像
  • 零遥测：不搜集使用数据，不上报崩溃，不埋分析点
  • 自主可控：密钥与工作区数据始终在你的机器上

核心能力

安全之外，同样好用

Plan 与 Agent 双模式、执行级验证、内联变更审查——把 AI 编程做成可审查、可回退的工程流程。

Plan + Agent

Plan 只读分析与方案；Agent 可编辑文件、执行命令、跑测试。先想清楚，再动手改。

执行级验证

改完自动跑类型检查、Lint 与关联测试；失败则进入自动修复循环，而不是“看起来能跑”。

内联变更审查

每次操作后展示逐文件 diff，支持单文件保留 / 撤销，以及全部保留 / 全部撤销。

写入与命令防护

三层写入策略阻止误改关键路径；危险命令需二次确认，超时默认拒绝（fail-closed）。

高缓存命中

面向真实账单优化上下文，缓存命中率可观，让日常迭代更省 token。

开放模型接入

兼容任意 OpenAI Chat Completions 接口：DeepSeek、通义、智谱、Moonshot 等均可自配。
